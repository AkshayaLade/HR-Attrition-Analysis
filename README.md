# hr-analytics-attrition-dashboard
This project focuses on analyzing employee attrition data to identify key factors contributing to employee turnover. The dashboard provides insights into attrition trends based on various factors such as department, age group, overtime, job satisfaction, work-life balance, salary band, and promotion cycles.

The goal of the project is to transform raw HR data into actionable insights that can help organizations improve employee retention strategies.

Key Features

Attrition Rate Analysis
Attrition by Department
Attrition by Age Group
Attrition vs Overtime
Attrition vs Job Satisfaction
Attrition vs Work-Life Balance
Attrition vs Years Since Last Promotion
Identification of High-Risk Employees

Tools Used

Power BI
Microsoft Excel
Data Cleaning & Transformation
Data Visualization
